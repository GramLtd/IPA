# Панель публикации видео в TikTok

Веб-панель: загружаете видео один раз, выбираете подключённые аккаунты, и оно публикуется на каждый (сразу или по расписанию, с интервалом между аккаунтами). Работает через официальный **TikTok Content Posting API**.

## Возможности
- Подключение аккаунтов через OAuth (Login Kit), автообновление токенов
- Загрузка mp4/mov/webm, разбивка на куски по правилам TikTok
- Публикация сразу (Direct Post) или черновиком во «Входящие» приложения
- Описание и хэштеги, приватность, отключение комментариев, дуэтов и stitch
- Расписание и интервал между аккаунтами
- Очередь со статусами, повтор и отмена заданий
- Вход в панель по логину и паролю (HTTP Basic)

## Подготовка в TikTok
1. Создайте приложение на https://developers.tiktok.com.
2. Добавьте продукты **Login Kit** и **Content Posting API**, включите Direct Post.
3. Scopes: `user.info.basic`, `video.publish`, `video.upload`.
4. Redirect URI: `https://ваш-домен/oauth/callback`.
5. **Важно:** пока приложение не прошло аудит TikTok, видео публикуются только как приватные (`SELF_ONLY`), и действует лимит на число пользователей. Для публичных постов подайте приложение на аудит.

## Запуск
```bash
cd panel
pip install -r requirements.txt
cp .env.example .env   # заполните ключи и PANEL_PASSWORD
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
Для OAuth панель должна быть доступна по HTTPS (nginx + certbot или туннель).

## Тесты
```bash
python -m pytest -q
```

## Устройство
- `app/tiktok.py` — клиент OAuth и Content Posting API
- `app/worker.py` — фоновая очередь: публикация, опрос статуса, обновление токенов
- `app/main.py` — веб-интерфейс (FastAPI + Jinja2), данные в SQLite (`data/`)

Лимиты TikTok: около 6 запросов init в минуту на пользователя и ограничение на число постов в сутки на автора. Ошибки показываются в очереди.
